# Security policy

This policy applies to the Frit app and to the code in this repository.

## Supported versions

Only the latest release gets security fixes. Update to the latest release before you report a problem.

## Report a security problem

Do not open a public issue for a security problem.

Use GitHub private vulnerability reporting.

1. Go to the [Security tab](https://github.com/theluckystrike/frit/security) of this repository.
2. Click **Report a vulnerability**.
3. Write what you found, the app name and version, your macOS version, and the steps to reproduce the problem.

Only the maintainer can see your report.

## What happens next

- You get a first reply in 7 days or less.
- We tell you if we accept the problem, and when we expect a fix.
- We publish a fix in a new release, and then a security advisory.
- We give you credit in the advisory if you want it.

Thank you for helping to keep Frit and its users safe.
