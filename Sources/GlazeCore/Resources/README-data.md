### Roles

Roles follow the column convention of the Seger / unity molecular formula (UMF):
- **flux** (R2O and RO): Li2O, Na2O, K2O, MgO, CaO, SrO, BaO, ZnO, PbO. The flux sum is set to 1.0 in the UMF.
- **stabilizer** (R2O3): Al2O3 and B2O3.
- **glassFormer** (RO2, R2O5): SiO2, TiO2, ZrO2, SnO2, P2O5.
- **colorant**: Fe2O3, MnO, CoO, CuO, Cr2O3, NiO. Colorants are reported in the UMF but are
  **not** counted in the flux unity, so a colorant addition does not change the flux ratios.

**B2O3 choice.** Chemically B2O3 is a glass former. In glaze practice it is written in the R2O3
column next to Al2O3 (it is amphoteric in the melt and it is usually compared with Al2O3 in
limit tables). GlazeCore uses role `stabilizer` for B2O3. The role only controls the flux unity:
B2O3 is never counted as a flux, so this choice does not change any UMF number.

### Expansion coefficients

Source: A. A. Appen, *Khimiya stekla* (Chemistry of Glass), 2nd ed., Leningrad: Khimiya, 1974
(the additive partial coefficients for linear thermal expansion, units 1e-7 per K per mole percent).
The constants were checked on 22 Oct 2026 against two public reproductions of Appen's table
(see section 6): all 15 constants that were already stored match. Fe2O3 (5.5), SnO2 (-4.5) and P2O5 (14.0)
were added from the same table (stored here times 10).

The table above holds the constants. Appen's composition-dependent terms are computed in
`Sources/GlazeCore/Appen.swift` (W6 F3, 26 Oct 2026) from the footnotes of the Appen column at
https://www.glassproperties.com/expansion/Old-Thermal-Expansion-Models.htm (A. Fluegel, citing Appen 1974).
Values times 10 (1e-7 per K); brackets are mole percent of the glass:

- **SiO2** (footnote a): 38 when [SiO2] < 67, otherwise 105 - [SiO2] (the table value 38 is the low-silica one).
- **K2O** (footnote d): 465 when [Na2O] > 1, otherwise 420.
- **B2O3** (footnote c): F = ([Na2O] + [K2O] + [BaO] + 0.7 ([CaO] + [SrO] + [PbO]) + 0.3 ([Li2O] + [MgO] + [ZnO])
  - [Al2O3]) / [B2O3]; coefficient -12.5 F for F <= 4, otherwise -50. The published range is -50 to 0, so
  F < 0 is outside the method and B2O3 is then not counted. (CdO is in Appen's F; GlazeCore has no CdO.)
- **PbO** (footnote e): 130 when [Li2O] + [Na2O] + [K2O] < 3, otherwise 115 + 5 x that sum. The published range
  is 130 to 190, so a sum above 15 is outside the method and PbO is then not counted.
- **TiO2** (footnote f): 105 - 1.5 [SiO2] for 50 <= [SiO2] <= 80. Outside that range TiO2 is not counted.
- **Cr2O3**: Appen's table has no value. Not counted.
- The Fe2O3 and MnO constants are valid for the normally occurring oxidation states only (footnote g),
  so a reduction firing can differ.

**Partial estimates.** When an oxide in the recipe is not counted, the estimate is partial:
`Chemistry.expansionNotCounted` lists the oxides, the calculator adds a warning that names each one and
the reason, and the chemistry pane labels the value "partial" and names the oxides. A partial sum is never
shown as a complete estimate.

**Convention (GlazeCalculator).** expansion = sum over oxides of (mole fraction x coefficient),
where mole fraction = moles of the oxide / moles of all oxides in the calculation (colorants
included; additions included only when `includeAdditions` is true). The result is in units of
1e-7 per K (for example 65 means 6.5e-6 per K). It is an estimate for comparing glazes, not a
measured value.

## 3. Materials

All bundled materials are theoretical (computed from a chemical formula) or generic frits defined
in this app. No commercial material is bundled: I could not fetch a manufacturer data sheet with
clear reuse terms in this session (the 3M nepheline syenite sheet returned HTTP 403), so named
commercial materials (nepheline syenite, EPK, Custer feldspar, commercial frits) are left out.
Users add them as custom materials from their supplier's sheet. No Glazy or Digitalfire data is used.

Method: parse the formula into element counts. Raw mass = sum(count x atomic weight).
Each non-volatile element becomes its oxide (Mn -> MnO, Fe -> Fe2O3, Co -> CoO, Cu -> CuO, ...).
H, C, N, S, F and the excess O leave as water, CO2 or O2. Analysis (wt% per 100 g raw material)
= oxide moles x oxide molar mass / raw mass x 100. LOI = (raw mass - fired mass) / raw mass x 100.

### Worked examples

**whiting** (CaCO3): raw mass = 1 x 40.078 + 1 x 12.011 + 3 x 15.999 = 100.0860 g/mol.
- CaO: 1 mol x 56.0770 g/mol = 56.0770 g -> 56.0770 / 100.0860 x 100 = 56.0288 %
- LOI = (100.0860 - 56.0770) / 100.0860 x 100 = 43.9712 %

**kaolin** (Al2Si2O5(OH)4): raw mass = 2 x 26.982 + 2 x 28.085 + 9 x 15.999 + 4 x 1.008 = 258.1570 g/mol.
- Al2O3: 1 mol x 101.9610 g/mol = 101.9610 g -> 101.9610 / 258.1570 x 100 = 39.4957 %
- SiO2: 2 mol x 60.0830 g/mol = 120.1660 g -> 120.1660 / 258.1570 x 100 = 46.5476 %
- LOI = (258.1570 - 222.1270) / 258.1570 x 100 = 13.9566 %

**potash-feldspar** (KAlSi3O8): raw mass = 1 x 39.098 + 1 x 26.982 + 3 x 28.085 + 8 x 15.999 = 278.3270 g/mol.
- K2O: 0.5 mol x 94.1950 g/mol = 47.0975 g -> 47.0975 / 278.3270 x 100 = 16.9216 %
- Al2O3: 0.5 mol x 101.9610 g/mol = 50.9805 g -> 50.9805 / 278.3270 x 100 = 18.3168 %
- SiO2: 3 mol x 60.0830 g/mol = 180.2490 g -> 180.2490 / 278.3270 x 100 = 64.7616 %
- LOI = (278.3270 - 278.3270) / 278.3270 x 100 = 0.0000 %

**manganese-dioxide** (MnO2): raw mass = 1 x 54.938 + 2 x 15.999 = 86.9360 g/mol.
- MnO: 1 mol x 70.9370 g/mol = 70.9370 g -> 70.9370 / 86.9360 x 100 = 81.5968 %
- LOI = (86.9360 - 70.9370) / 86.9360 x 100 = 18.4032 %

## 4. Reference limit sets (`Limits.swift`)

Sections 4 to 6 are kept in `tools/README-sections-limits-stull.md`; `tools/gen_data.py` appends them here.

The bundled sets are **reference ranges** in UMF (flux sum 1.0) from two published tables. The app
uses them for comparison only. They are not a durability or safety rating, and the app labels do not
use the source authors' own words for that purpose.

Sources:
- **Hesselberth & Roy** (sets `hr-cone6`, `hr-cone10`): J. Hesselberth and R. Roy, "Making Stable Glazes
  for Functional Stoneware and Porcelain", *Ceramics Monthly*, September 2000. The values come from the Arbuckle handout below. The cone 6 KNaO reading was checked against the article text. The article gives one cone 6 column
  and one cone 10 column.
- **Val Cushing** (sets `cushing-c5-6-gloss`, `-satin`, `-matt`, `cushing-c9-10-gloss`, `-satin`, `-matt`):
  Val Cushing, *Cushing's Handbook* (limit tables for gloss, satin and matt glazes). I did not check the
  book itself; the numbers come from the reproduction below.
- Both tables as typed in L. Arbuckle (University of Florida), "Molecular Glaze Limit Ranges", handout,
  2012, https://www.lindaarbuckle.com/handouts/glaze-limits.pdf (text extracted with `pdftotext -layout`
  on 22 Oct 2026, lane G8). Digitalfire limits are not used (SPEC rule 6).

- **KNaO** ((K+Na)2O) is one `LimitRange` on K2O with `combinedWith: [.Na2O]`. `Limits.check` compares

  oxide is not checked. The article has no row for these oxides.
- **PbO** ranges in the Cushing tables are not bundled.

## 5. Stull chart (`Stull.swift`)

Source chart: R. T. Stull, "Influences of variable silica and alumina on porcelain glazes of
constant RO", *Transactions of the American Ceramic Society* 14 (1912) 62-70, Chart 1 (public domain).
Stull fired a grid of glazes with RO fixed at 0.3 K2O / 0.7 CaO, at cone 11, with SiO2 on the x axis
(0.6 to 7.2) and Al2O3 on the y axis (0.1 to 1.0), and mapped the fired surfaces.

Reproduction used: the image of Chart 1 at https://digitalfire.com/glossary/stull+chart (only the
1912 chart image was read; no Digitalfire data is bundled). Lane G7 read the lines from that image
by eye (about +-0.05 UMF) on 22 Oct 2026; the readings are in `~/glaze-work/G7-REPORT.md`, section 3.
The published boundaries are curves; GlazeCore uses straight lines through the read points.
Cross-checks: Bloomfield, *Special Effect Glazes* (lines 1:4 matt, 1:5 semi-matt, 1:8 bright,
1:12 crazed; "Data from R.T. Stull 1912"); S. McLeod, *Ceramics Monthly*, Summer 2023 (satin at
SiO2:Al2O3 5-6, glossy at 7-10, underfired risk near 12); Marzano, McComb and Coppage,
*Ceramics Monthly*, February 2025 (the lines are curves; no crystallization zone; not valid for
boron glazes).

Limits of use: the chart is for 0.3 K2O / 0.7 CaO at cone 11. At cone 6, and for glazes with B2O3,
the regions are only a rough guide.

Rules, applied in this order (x = SiO2, y = Al2O3, UMF):

1. **unknown**: x or y not finite, x outside 0.6-7.2, or y outside 0.1-1.0 (outside the chart).
2. **unfused**: y > 0.44 + 0.25 (x - 0.6) (line M-J, top left).
3. **matte**: y > 0.10 + 0.25 (x - 0.6) (line N-U, slope about 1:4).
4. **semimatte**: y > 0.10 + 0.20 (x - 0.6) (line N-K, slope about 1:5).
5. For x >= 2.4:
   - **underfired**: y < 0.10 + 0.108 (x - 2.4) (curve O-S through (2.4, 0.10), (4.2, 0.30), (7.2, 0.62); lower right).
   - **crazing** (crazed or devitrified band just above O-S): y < 0.23 + 0.0583 (x - 3.0)
     (through (3.0, 0.23) and (4.2, 0.30)). Above x 4.3 the underfired line is higher, so the band ends there.
6. For x < 2.4: **crazing** when y < 0.25 (the hatched area at the bottom left).
7. Otherwise **gloss**.
